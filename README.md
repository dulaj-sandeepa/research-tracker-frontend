# Research Tracker - Frontend

This is the frontend client application for the Research Tracker project, built using React and modern web technologies. It provides a clean, responsive user interface to manage, monitor, and visualize research workflows, documents, and timelines.

---

## 🛠️ Tech Stack & Features

- Framework: React (via Vite build tool)
- Styling: Responsive CSS layout
- State Management: React Hooks (useState, useEffect)
- Key Components: Project Dashboard, Document Repository, Milestones Tracker

---

## 📂 Project Structure

The project follows a standard modern frontend React architecture:

src/
- components/ (Reusable UI components like Navbar, Sidebar, and Tables)
- pages/ (Main view layouts like Dashboard, Login, and Projects)
- assets/ (Static media, images, and global icons)
- App.jsx (Main application routing and core wrapper)
- main.jsx (Application entry point and DOM rendering)

---

## ⚙️ Prerequisites

Before running the user interface locally, ensure you have:
- Node.js (Version 18 or higher recommended)
- npm (Node Package Manager, installed automatically with Node.js)
- A running instance of the backend service (on port 8080)

---

## 🚀 Getting Started

1. Install Dependencies
Open your terminal inside this root frontend directory and run:
npm install

2. Run the Development Server
To launch the application interface locally, execute:
npm run dev

The application will start, usually accessible at http://localhost:5173 or the URL printed in your terminal.

---

## 🧪 Build for Production

To compile and optimize the frontend application for production deployment, run:
npm run build
